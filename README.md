# Jonesco Art Dept.

Landing page for the Yōkai Coloring Book, served by GitHub Pages at https://jonescoartdept.com.

- `index.html` is the whole site. Products (prices, Amazon links, sizes) are in the `PRODUCTS` list near the bottom.
- `images/` holds the cover and the sample pages.
- `CNAME` tells GitHub Pages which domain to serve.

Push to `main` to publish.
